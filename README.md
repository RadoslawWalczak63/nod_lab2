# Nauka o danych – Laboratorium 2

Podstawowe operacje arytmetyczne w analizie danych: średnia, mediana, odchylenie standardowe, wariancja, korelacja i kowariancja (numpy, pandas).

**Zbiór:** XAUUSD Gold Price Historical Data (2004-2024), plik `XAU_15m_data.csv`

## Pliki

- `lab2_podstawowe_operacje.ipynb` – notatnik z rozwiązaniem: część A (ceny złota) i część B (dane o paleniu z lab1, wymaga pliku CSV z `lab1`)
- `lab2_sprawozdanie.pdf` – sprawozdanie
